## Things I've built

**[MARSVISUAL](https://marsvisual.com)**: booking and photo delivery for a Philadelphia photo studio. Clients request a shoot, the studio approves it, and approval sends a Stripe link for a 50% deposit. A webhook confirms the booking when it's paid. Galleries live in Cloudflare R2, and a GitHub Actions job sends reminders every 10 minutes.
`React` `FastAPI` `MongoDB Atlas` `Stripe` `Cloudflare R2` `Resend` · *client code, private*

**[Dayo Vault](https://github.com/amadoug1/dayo-vault)**: a self-hosted file vault with no upload limit. It streams uploads to disk, extracts text, transcribes audio and video with Whisper, and searches everything with SQLite FTS5.
`Python` `FastAPI` `SQLite` `ffmpeg` `React`

`React` `FastAPI` `MongoDB` `Stripe`
